# Room Redesign: demo site

Static demo (HTML, CSS and plain JavaScript, no build step) for a personal room redesign project: home, process, results and contact pages.

- Photos are sample images from Unsplash; replace them with your own in `img/`.
- Contact details and figures are placeholders.
- The contact form runs in demo mode. To receive messages, add `data-endpoint="https://formspree.io/f/YOUR_ID"` to the `<form>` in `contato.html`.
